# AI-Assisted-Crypto-Futures-Trading_Hedgebot__Toobit
AI-Assisted-Crypto-Futures-Trading_Hedgebot__Toobit


Trading bot to communicate with API of futures exchange: Toobit
writtin in: nodejs javascript

Should be able to:
- connect via API and consume its REST endpoints
- get prices for a given pair
- another separate algorithm to find the best pair to trade on can be considered an extra idea for when this while bot is optimized
- open market orders
- set trigger open orders
- set limit open orders
- set trigger close orders
- set limit close orders
- set trailing stoploss
- monitor and display position, extract position size, ROI, PnL, closedPnl, etc of open positions
- store and chart historical data of the position and display it: available balance, longRoi, shortRoi, roiDiff availableBalancePct, equity
- backtest on imported or saved historical candle and price data, to recreate a position to compare with actual logs, if successfull the backtest can be applied to other paramers
- have a list of parameters values to finetune different strategies
